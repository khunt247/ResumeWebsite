# Resume Website

This project is a **high-performance resume website** designed with a sleek, dark, Nike-inspired theme.  
It highlights professional experience, technical skills, certifications, projects, and education in an interactive and visually engaging manner.

## Features
- **Modern UI** with animated section reveals and smooth hover effects
- **Nike-inspired background** with animated SVG shapes
- **Professional Experience** with aligned job titles and dates
- **Interactive Technical Skills** section with gradient hover-lift effect
- **Projects & Technical Experience** cards with hover animations
- **Certifications** gallery with modal pop-ups to view PDFs
- **Education & Background** timeline
- **Featured Presentations** embedded from Prezi and OneDrive
- **Download Resume** button with animated pulse

## Technologies Used
- HTML5, CSS3, JavaScript (Vanilla)
- Google Fonts (`Barlow`)
- Font Awesome icons
- Responsive design for desktop and mobile

## How to Use
1. Download the HTML file and all related certificates/PDFs.
2. Place the files in the same directory to ensure modal pop-ups work correctly.
3. Open the HTML file in any modern web browser.
4. Scroll to view sections — animations will trigger on scroll.

## Adding New Certificates
To add a new certificate:
1. Place the PDF in the project directory.
2. Add a new `.cert-thumb` block in the `Certifications & Training` section of the HTML.
3. Add a corresponding entry in the `certDetails` array in the JavaScript.

## Customization
- Modify the colors and gradients by editing CSS variables in the `:root` selector.
- Update personal info, job experience, or skills directly in the HTML.
